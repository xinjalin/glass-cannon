Healing and damage taken, skill tooltips with each player's specialties, a click-through
lock, and the game data now ships in the repository.

![Fight analysis: skills with a tooltip](https://raw.githubusercontent.com/xinjalin/glass-cannon/v0.5.0/docs/screenshots/analysis-skills.png)

### New in the meter

- **dmg / heal / taken**: the button by the fight clock switches the rows between damage
  dealt, healing done and damage taken (saved for next time).
- **End fight** (▷|): ends the fight now; your next hit starts a new one.
- **Lock** (bottom-right corner): clicks go through the meter to the game. While locked,
  only the lock button takes the mouse.
- **Update rate** in the settings: 0.2 s, 0.5 s, 1 s or 2 s.
- Elementalist spirits count for the Elementalist instead of showing as a separate `#ID`
  player.
- Player names are remembered for the rest of your login, so restarting the meter doesn't
  lose them.

### New in the analysis window

- **Healing** and **taken** tabs: over time, per player, and by skill and by who was
  healed (or which mobs hit them). Healing counts heals over time and heals players cast
  on themselves, by the HP they actually restored.
- **Specialties**: the skills tab shows which specialties each player chose, read from the
  skill IDs the game sends.
- **Skill tooltips**: hover a skill for its cooldown, cost, range, description and all its
  specialties, the chosen ones ticked. The game doesn't send skill levels, so descriptions
  show level 1 and the top level.
- **[copy text]** puts a table of the fight on the clipboard for Discord; **[copy image]**
  copies a summary card.
- Zoomed in to the end of a live fight, the rotation and buff timelines follow it; **[now]**
  jumps there.
- Theostones and buffs without a skill are named (with their own icons for Theostones).

### Fixes

- Skill icons that finished loading after a fight now show up.
- Timeline and chart labels no longer run off the right edge.
- The settings' status has a **skill info** line showing whether the skill details loaded.

### Game data

The `gamedata` folder is now part of the repository, so builds don't download anything.
It has about 2,200 more skill names than before (from RATmeter), and skill details
(cooldowns, descriptions, specialties) scraped from aion2.app. None of it is under Glass
Cannon's MIT licence: see `gamedata/README.md` in the zip.

### Not yet

Parries aren't decoded, and heals cast on other players haven't appeared in our captures
yet.

Upgrading: extract over the old folder (the `gamedata` folder is replaced). Your settings,
names and history stay.
