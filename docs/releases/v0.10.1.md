Fewer boss warnings, and none with the widget turned off.

### Fixes

- **No chime while boss warnings are turned off.** The chime played for every dangerous
  boss cast even with the boss warnings widget turned off.
- **Fewer, better warnings.** A boss cast now counts as dangerous from 2.5 s of cast time
  (it was 2 s), or when it marks the ground, as before. Bosses' short 2.0–2.2 s casts
  chimed every few seconds in a fight: on a Vakron Sky Island run, 11 warnings in a few
  boss fights became 3. Any boss skill can still be set to always or never warn in the
  analysis window's [boss] tab.
