A farming widget: what you gain and at what rate, read from your inventory.

### Added

- **The farming widget** (settings → overlay → farming). A row an item, with how many you
  gained since the last reset and the rate, and the run's time over them. It lists Abyss
  Points, Kina (Bound) and Kina to begin with, and is as tall as its rows.
  - **↺ in its top right corner** starts the run over: the first click asks (*reset?*), a
    second within three seconds does it. Clicks anywhere else on the widget go through to
    the game.
  - **Its settings are beside it** while the overlay is arranged (⚙):
    - **[show]**: the run time, the reset button, the amount gained and the rate, each on
      or off; **everything gained**, which adds every other item that went into your
      inventory this run (souls, materials, gear, other currencies), the most first; the
      rate per hour or per minute, over the whole run or only its last 5, 15 or 60
      minutes.
    - **[items]**: the items listed (click one to hide it), what else you gained this run
      (click one to always list it), and a search by name for any other item. Each shows
      what the run has of it, how many you have, and what you spent or used.
- **It reads the game's own count** of each stack you carry (currencies are items too), so
  the numbers are exact and it works anywhere: the Abyss, a dungeon, gathering, the
  market. On a recorded Abyss run of 418 kills it counted 36,485 Abyss Points, the same
  as the game's own counter.

### Notes

- A run starts with the first thing you gain and ends with a reset or when the app
  closes. The time doesn't stop while you stand still: use the 5, 15 or 60 minute rate to
  see what a spot pays now.
- Only gains count toward a rate. What you spend takes nothing off.
- Rows are text: no item icons yet.
- Items are named from a new data file (2,368 materials, consumables and currencies); one
  it doesn't know shows as "Item" and its number.
