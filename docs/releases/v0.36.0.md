The overlay steps aside for loading screens.

### Added

- **Hide for loading screens** (settings → over the game, on by default). The widgets go
  while the game loads a map (entering a dungeon, a raid or an arena, a teleport, logging
  in) and come back a moment after you're on it. It works from the game's own messages,
  so nothing on screen is looked at; the launcher says "hidden for a loading screen" while
  it applies. Should a message be missed, the overlay is back within a minute.
