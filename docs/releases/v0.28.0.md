Set up every boss's casts, and the Pantheon in your collection.

### New

- **Boss casts** (settings → alerts → boss casts [ set up ]): every boss by content
  (expeditions, transcendence, raids, the arena, sealed dungeons, strongholds, invasions,
  field bosses) and dungeon, with each cast the meter has seen it make: its cast time,
  when it lands, how often it's been seen, its skill ID. Rename any cast (the name shows
  everywhere), and choose for each whether it shows in the **boss warnings** and the **boss
  timers**: auto, on or off. The casts come from your fights with the meter running (and
  the fights already in your history).
- **Pantheon in the collection**: every artwork, statue and colossus, which your
  characters have (and which are placed), with their stats.

### Changed

- Boss moves the game itself only calls "Attack" show as **unnamed** in the boss casts
  window, with their skill ID; every name the game's own text has is already used.
