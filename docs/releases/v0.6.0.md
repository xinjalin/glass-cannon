Dungeon runs in the history, and an analysis of a whole run.

![Dungeon runs in the history](https://raw.githubusercontent.com/xinjalin/glass-cannon/v0.6.0/docs/screenshots/history.png)

### New

- **Dungeon runs**: the history groups the fights of a dungeon into one run, with the
  dungeon, its type and mode (*Transcendence · Stage 2*, *Expedition · Conquest*), when it
  started, the time spent fighting, its fights and bosses, the most players and the total
  damage. Click a run to show or hide its fights; the newest starts open. Mobs the data
  doesn't place (adds, summons) count toward the run they're fought in, and running the
  same dungeon again straight away starts a new run once a boss comes round again.
- **Right-click a run** in the history for the whole run in the analysis window: its
  fights back to back (time spent fighting), with every player's damage, skills, healing
  and damage taken added up and a dashed line where each fight starts. Right-click a fight
  in the history for that fight. Right-click again to close the window.
- The analysis window's title says which dungeon and mode a fight was in.
- Scroll, potion and food buffs have their icons (Courage Scroll, Speed Scroll, Benediction
  Scroll, Mana Potion and 94 more).

### Game data

`dungeons.json` lists which dungeon and mode each of 1,536 dungeon mobs is in (19
dungeons), taken from a scraped monster database collected from public fan databases.
Like the Theostone effects, it isn't covered by Glass Cannon's MIT licence: see
`gamedata/README.md` in the zip.
